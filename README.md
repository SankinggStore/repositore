# 🚀 Sankigg Store — HTML, CSS & JavaScript

Bem-vindo ao repositório público da **Sankigg Store**! 🌐

Este projeto reúne uma coleção de **códigos, templates, componentes, snippets e projetos web** desenvolvidos com **HTML, CSS e JavaScript**.

Nosso objetivo é compartilhar recursos úteis para desenvolvedores, estudantes, designers e criadores que desejam **aprender, testar e desenvolver projetos para a web**.

## 💻 Como utilizar

Clone o repositório:

```bash
git clone https://github.com/SankinggStore/repositore.git
```

Entre na pasta:

```bash
cd repositore
```

Depois, abra os arquivos HTML no navegador ou utilize uma ferramenta como **Live Server** para facilitar o desenvolvimento.
